Challenge #578

Atomic secable

Herr Performances sucht nach einem effizienten Algorithmus zur Skalarmultiplikation auf einer elliptischen Kurve, der gleichzeitig vor physischen Angriffen schützt.

Er hat sich für eine Implementierung des Additionsgesetzes auf der Kurve entschieden, die das Prinzip der Atomizität respektiert. Dieses Prinzip beruht auf einer einzigen Operationssequenz zur Berechnung der Punktverdopplung oder der Addition zweier verschiedener Punkte. Dies bietet einen sehr guten Schutz gegen Angriffe durch Laufzeitanalyse oder Analyse von Seitenkanalspuren. Dieser Schutz ist in der Tat notwendig, da die Unterscheidung der ausgeführten Operation (Verdopplung oder Addition) Rückschlüsse auf die Bits des Skalars ermöglicht, der geheim bleiben soll.

Durch das Hinzufügen von Scheinoperationen (Dummy-Operationen) ist es recht einfach, zwei identische Sequenzen für eine Verdopplung und eine Addition zu erhalten, dies ginge jedoch zu Lasten der Leistung.

Herr Performances bleibt seinen Prinzipien treu und verwendet eine Sequenz ohne Leistungsverlust! Seine Sequenz ist an Kurven der Form y^2 = x^3 + b angepasst und enthält nur 9 modulare Multiplikationen. Er fordert Sie heraus, seine Implementierung für die Standardkurve secp192k1 (die diese Form hat) mithilfe eines Fehlerangriffs (Fault Attack) zu brechen. Er hat jedoch Gegenmaßnahmen implementiert, um einen solchen Angriff einzuschränken:

- Die Bits des Skalars werden vor dem Start einer Sequenz zweimal gelesen (und verglichen);
- Die finalen Koordinaten (x, y) müssen einen Punkt auf der Kurve bilden.

Dazu stellt er seinen kommentierten Assemblercode zur Verfügung, der die Multiplikation mit dem Generator auf der Kurve berechnet. Im Rahmen der Challenge wird der Code in einer virtuellen Maschine ausgeführt, und es können die zu manipulierenden Befehle angegeben werden. Es gibt keine Begrenzung für die Anzahl der zu fehlerhaften Instruktionen, aber das Fehlermodell besteht lediglich darin, dem Zielregister der Operation einen Zufallswert zuzuweisen. Um beispielsweise die ersten drei Befehle fehlerhaft auszuführen, geben Sie nach dem Prompt 0 1 2 (getrennt durch Leerzeichen) ein.

Die Dokumentation der virtuellen Maschine ist auf dieser Seite verfügbar.
